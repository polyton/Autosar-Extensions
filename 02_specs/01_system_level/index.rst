System level
============

The system-level specifications describe system behavior, interfaces,
constraints, diagnostics, and allocation to vehicle or ECU functions.

Specification entry template
----------------------------

Use the following fields for each system-level statement:

* **ID:** ``SYS-<number>``
* **Source:** product requirement or external specification
* **Description:** concise, testable system behavior
* **Interface:** signal, service, diagnostic, or communication interface
* **Allocated to:** system element or ECU function
* **Satisfied by:** linked software-level specification
* **Validated by:** system test or review
* **Version:** specification version
