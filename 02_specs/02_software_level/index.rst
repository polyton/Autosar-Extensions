Software level
==============

The software-level specifications describe AUTOSAR software behavior,
ports, runnables, timing, data handling, and integration constraints.

Specification entry template
----------------------------

Use the following fields for each software-level statement:

* **ID:** ``SW-<number>``
* **Source:** system-level requirement or software design decision
* **Description:** concise, testable software behavior
* **AUTOSAR element:** SWC, port, interface, runnable, or service
* **Implemented by:** software component or module
* **Verified by:** unit, integration, or software qualification test
* **Traceability:** linked system-level specification
* **Version:** specification version
