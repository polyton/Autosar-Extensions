# Autosar-Extensions

Extensions and tools for AUTOSAR development.

## Clone the repository

```bash
git clone https://github.com/polyton/Autosar-Extensions.git
cd Autosar-Extensions
```

## Checkout a branch

After cloning, switch to the branch you want to work on:

```bash
git checkout <branch-name>
```

If you want to create a new branch from the current state:

```bash
git checkout -b <new-branch-name>
```

## Project structure

The repository is organized into numbered areas for documentation, specs, architecture, software, tests, tools, and build artifacts:

- 01_docs
- 02_specs
- 03_arch
- 04_sw
- 05_tests
- 06_tools
- 07_build
